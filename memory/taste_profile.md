## 商业模式偏好

- **"王者归来"模式(P1)** [已验证]:偏好曾被市场情绪爆炒 → 股价暴跌 → 公司用业绩数据证明原始逻辑 → 股价再次大幅上涨的标的。典型案例:Palantir(美股)、汇聚科技01729(港股)。核心逻辑:情绪溢价消退后买入"被验证的正确",赔率与胜率同时改善。**新信号(6-8月)**:P1 候选已从科技扩展到消费/医疗/游戏——LULU、BDX(百年王者)、TEAM(距高-45.6%)、任天堂7974.T(距高-47.6%,Mario电影催化剂)均获标注,表明 P1 是跨行业通用框架而非板块偏好。
- **瓶颈猎手(P4,Chokepoint Theory)** [已验证,由初步推断升级]:2026-06 分享 Serenity 方法论后,6-8 月的标注行为持续印证——CLS/COHR/PWR/IRM/NBIS/CRDO 全部按"物理卡点×机构盲区×低位介入"框架标注与跟踪,且严格执行 52 周位置校验(见三份复盘)。P4 已在 patterns.md 启用,参与每周狩猎。
- **AI基础设施供应链(全链条)** [已验证]:兴趣已从光纤/线缆(01729)扩展到整条链:光互联(COHR/CRDO/POET)、存储(MU/SNDK)、电力(GEV/PWR/IREN)、ODM(CLS)、neocloud(NBIS/CRWV)、定制芯片(AVGO/CBRS)。对应假设 H6(价值向"隐形卡点"层迁移,状态:增强)。

## 买入风格

- **左侧埋伏 + 右侧大举加仓** [已验证]:数据证实前小仓位左侧布局,客户数据增长证明逻辑后大举买进。典型案例:Palantir、汇聚科技(2022)。
- **价格纪律:等待 52 周下三分之一** [已验证,新增]:6-16/7-19/7-26 三份复盘一致验证——CLS/COHR 在 77%-88% 高位时坚持不入,等到 -22%~-33% 回调,方向判断全部正确。这是画像中执行最稳定的纪律。
- **执行弱点:买在反弹而非底部** [已验证,新增·警示]:COHR 案例——系统在 $277.6 推荐,实际标注"喜欢"于 $317.94(高 15%),随后回落至 $282。教训:回调等到后,介入点仍偏向"反弹确认"而非"低位区间",与左侧埋伏的自我定位存在执行偏差。复盘建议:预设介入价格区间,到价执行,减少情绪追入。
- **验证信号:客户数据增长** [已验证]:判断"逻辑被证明"的核心指标是客户数量/使用数据增长,非单纯盈利或股价。
- **重仓前提:举证充分** [已验证,由初步推断升级]:2026-08-02 标注纪律修订采纳"喜欢=举证充分愿建仓",制度化了这一原则。
